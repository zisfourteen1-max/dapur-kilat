Dapur Kilat — a fast Indonesian warung cooking game. Orders land on the board with a timer ticking; you run the kitchen, chop ingredients, cook them in the wok, plate the dish and serve it before the customer's patience runs out. Four recipes to master — nasi goreng, mie goreng, sate ayam and es teh — with the rush growing every 45 seconds until the 3-minute shift ends.

## Run it

```sh
python3 -m http.server 8080 --directory game
# open http://localhost:8080
```
